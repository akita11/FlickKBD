# FlickKBD

<img src="https://github.com/akita11/FlickKBD/blob/main/FlickKBD.jpg" width="240px">

静電容量式タッチ検出を使った名刺サイズのフリック入力キーボードです。PC等にUSB(Type-C)で接続し、キーボードとして使うことができます。
かな（ローマ字入力）、英字、数字の3つのモードがあります。

※感度・入力速度はサポートページ内の動画からご確認ください。スマホのフリック入力ほどの実用性はありませんのでご了承ください。またPC等側のキーボードの設定（英字キーボード等）によっては、表示されているものと異なる文字が入力されることがあります。またタッチ検出の補正動作によって、非タッチ時にタッチが検出されてLEDが消灯している場合は、少し待つとLEDが点灯して入力できるようになります。

[動作原理と使用例（動画）(ProtoPedia)](https://protopedia.net/prototype/9148)


## 使い方

本機のUSB Type-Cコネクタ（基板と一体化）にUSB Type-Cケーブルを刺し、PC等に接続します。
PC等からはUSBキーボードとして認識されます。
（本機には2つのUSBコネクタがありますが、どちらでもOKです）

### 文字入力

やや強めにタッチしつつゆっくり移動させてフリック入力ができます。
（カッコ内は、左上のキーの場合の入力される文字例）

- タッチのみ: 基本文字（"a"）
- タッチ後、左にマス目の半分ほど移動：左フリック（"i"）
- タッチ後、上にマス目の半分ほど移動：上フリック（"u"）
- タッチ後、右にマス目の半分ほど移動：上フリック（"e"）
- タッチ後、下にマス目の半分ほど移動：上フリック（"o"）

LED表示は以下の意味で、タッチやフリック動作の検出状況を確認できます。
- 非タッチ時に点灯
- タッチ時に消灯
- 左or右フリック検出時に1回点滅
- 上or下フリック検出時に2回点滅、

なお、かな（ローマ字）入力モード時に"A/a"キー（左下）を押してから（LEDがやや暗くなる）文字入力を行うと小文字が入力されます。（例："あ(a)"→"ぁ(xa)"

また、アルファベット入力モード時に"A/a"キー（左下）を押すと、大文字／小文字モードが切り替わります（小文字入力時はLEDがやや暗くなります）

### 入力モード

"あA1"キー（右端上から2つめ）を押すと、入力モードが切り替わり、以下のようにLEDの色が変わります。

- かな（ローマ字）入力モード: 緑
- アルファベット入力モード: 青
- 数字・記号入力モード: 赤


## プログラムの書き換え

ArduinoIDEに、[CH55xduino](https://github.com/DeqingSun/ch55xduino)をインストールし、2つのUSBコネクタからそれぞれのマイコン(CH552)に書き込みます。
事前に、TouchKey.{c,h}を、ArduinoIDEフォルダ内のCH55xduinoフォルダのTouchKey/srcにコピーしてださい（念のため、オリジナルのCH55xduinoの両ファイルはバックアップをとっておいてください）。
（Macの場合は、~/Library/Arduino15/packages/CH55xDuino/hardware/mcs51/0.0.26/libraries/TouchKey/src）
- USB Settingを"USER CODE w/128B USB RAM"に変更
- 上側のUSBコネクタ: FlickKBD.ino中の"#define DEV_R"をコメントアウトし、書き込み
- 右側のUSBコネクタ: FlickKBD.ino中の"#define DEV_R"を残して、書き込み

<img src="https://github.com/akita11/FlickKBD/blob/main/FlickKBD-mode.jpg" width="240px">

なおブランクのCH552に初回書き込み時以外は、CH552を、以下の手順でダウンロードモードに設定してください。
- 右側のUSBコネクタ使用時: 裏面の上図の"1-2"間をジャンパ線等でショートした状態で右側USBコネクタに接続し、1秒ほど保持してからショートを解除する
- 上側のUSBコネクタ使用時: 裏面の上図の"2-3"間をジャンパ線等でショートした状態で右側USBコネクタに接続し、1秒ほど保持してからショートを解除する
